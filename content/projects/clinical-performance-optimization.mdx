## Context

Between July 2024 and August 2025 I worked at Cloud Data Systems on healthcare applications in daily clinical use, in a regulated clinical environment. The work spanned the whole stack: React Native and Next.js on the client side, Node.js and Spring Boot services behind them.

<Inferred>The applications needed faster UI response and lower backend latency.</Inferred> The published record describes the outcome, not the symptoms that triggered the work, so that sentence is an inference from the result rather than a statement from the source documents.

## Constraints

- A regulated clinical environment: the client, the product and the clinicians who used it stay unnamed here, and no screenshots or real charts appear on this page.
- Applications already in daily use: changes had to land without disrupting people doing clinical work.

## What I built

Application performance improved through front-end optimization on the React Native and Next.js clients and restructuring of the Node.js and Spring Boot services behind them. Both figures below belong to that combined effort; neither side is credited alone.

## What changed

- UI responsiveness rose by 45%.
- Backend latency fell by 30%.
- Critical applications stayed stable under real clinical load, which is the point of performance work in a clinical setting.

## Stack

React Native and Next.js on the client, Node.js and Spring Boot services, with automated tests and containerized deployment covered in the companion case studies on [testing](/projects/clinical-automated-testing) and the [cloud-native migration](/projects/cloud-native-migration-docker-kubernetes).
