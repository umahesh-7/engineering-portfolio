## Context

At Cloud Data Systems in Albany, through January 2024, I built responsive and secure front-end applications with React Native, Next.js and TypeScript, paired with robust REST APIs using Spring Boot. The backend services were OAuth2-secured and ran against MySQL.

## Constraints

- Client applications, so the clients, their domains and their data stay unnamed.
- Security was part of the brief rather than an afterthought: the services were secured with OAuth2 from the start.

## What I built

- OAuth2-secured backend services on MySQL, behind REST APIs built with Spring Boot.
- Query optimization on those services, with performance gains of up to 25%.
- React Native, Next.js and TypeScript front ends paired with those APIs.
- Factory and Singleton patterns applied to keep the codebase modular.

<Callout type="note" title="What this page does not claim">
  The published record does not describe the token or session design or say which queries were tuned and how the gain was measured, so this page does not either.
</Callout>

## What changed

- Query performance improved by up to 25%.
- The front ends shipped with secured services behind them rather than security added later.

## Stack

Spring Boot, OAuth2, MySQL, React Native, Next.js, TypeScript.
